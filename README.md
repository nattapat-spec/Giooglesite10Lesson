# แผนการสอน: การสร้างเว็บไซต์ (ฉบับรวบรัด 10 ครั้ง)

เว็บไซต์แผนการสอนหลักสูตร "การสร้างเว็บไซต์" ฉบับรวบรัด 10 ครั้ง จัดทำเป็นหน้าเว็บ HTML แบบ static ไม่ต้อง build หรือติดตั้งอะไรเพิ่มเติม

## โครงสร้างไฟล์

```
index.html          หน้าแรก แสดงภาพรวมแผนการสอนทั้ง 10 ครั้ง
lessons/
  lesson-01.html     เนื้อหาครั้งที่ 1
  lesson-02.html     เนื้อหาครั้งที่ 2
```

> หมายเหตุ: ขณะนี้มีเนื้อหาเฉพาะครั้งที่ 1–2 เท่านั้น ส่วนครั้งที่ 3–10 ที่ลิงก์ไว้ในหน้าแรกยังไม่ได้สร้างไฟล์ (จะขึ้น 404 จนกว่าจะเพิ่มไฟล์ `lesson-03.html` … `lesson-10.html` เข้าไปในโฟลเดอร์ `lessons/`)

## วิธีเปิดดูเว็บไซต์

เปิดไฟล์ `index.html` ด้วยเบราว์เซอร์ได้โดยตรง หรือถ้าจะเผยแพร่ออนไลน์ให้เปิดใช้งาน **GitHub Pages** จากในตั้งค่าของ repository นี้ (Settings → Pages → เลือก branch `main` และโฟลเดอร์ `/root`)

## เกี่ยวกับ

จัดทำเพื่อใช้ในการวางแผนและสอนวิชาการสร้างเว็บไซต์ (โดยใช้ Google Sites เป็นเครื่องมือหลัก)
